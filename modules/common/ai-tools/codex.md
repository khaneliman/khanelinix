## Codex Delegation

Delegate bounded multi-file discovery, noisy probes and tests, and parallel fact
slices to the smallest configured worker. Keep planning, integration, and final
judgment in main thread. Pass only task, paths, constraints, allowed tool or
skill lane, and exit criteria; consume an evidence packet.

Apply the shared model and effort policy. Pass an explicit `reasoning_effort`
when a task needs a level different from inherited `xhigh`. If the host rejects
a named agent with `agent type is currently not available`, use an unnamed
worker or built-in `default`, let `[agents]` defaults route it, and report that
the named role did not run.

Prefer Spark-backed `mechanic` and `checker` for obvious mechanical edits and
one focused known check. Use Luna-backed `explorer`, `fact-finder`,
`probe-runner`, and `test-runner` for average repository work and noisy
validation. Use Luna-backed `implementer` when the preferred Opus route is not
available. Use Sol-backed `reviewer` for review and hard diagnosis. Keep Terra
explicit-only.
