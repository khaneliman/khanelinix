# Research Method

Use this reference only when the question needs a repeatable research method or
the user explicitly requests a cited repository artifact.

## Source Order

Prefer sources in this order:

1. Official specifications and standards.
2. First-party API, product, or project documentation.
3. First-party source code, changelogs, issue trackers, or release notes.
4. Maintainer statements that directly address the question.

Use secondary sources only to locate primary sources. Do not use them as the
sole support for a material claim.

## Claim Record

For each material claim, record:

- Claim: one testable statement.
- Source: title, owner, stable locator, and access date when useful.
- Evidence: the relevant section, symbol, endpoint, or excerpt summary.
- Scope: version, platform, date, and assumptions.
- Confidence: high, medium, or low, with the reason.

Do not copy long source passages. Summarize evidence and preserve exact
identifiers, version numbers, constraints, and citations.

## Artifact Contract

Write an artifact only when the user explicitly asks for one. Before writing:

1. Confirm the exact path or repository convention.
2. Keep the artifact limited to the requested question.
3. Cite every material claim at the point of use.
4. Separate observed facts, inference, and open questions.
5. Verify links, dates, versions, and source coverage after writing.

If no path is supplied, ask for one when choosing a repository location would
change project state. Do not create task notes, plans, or ADRs by default.
